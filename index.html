      Traduction en Python

      Une instruction par ligne, ou plusieurs séparées par des points. Ce qui se répète ou dépend d’un « si » se décale vers la droite, comme en Python. Pour donner une valeur : m <- 0, m ← 0, m = 0 ou « m prend la valeur 0 ». S’il manque quelque chose, une question s’affiche. La traduction ne corrige rien : l’animation montre ce que fait vraiment la démarche.

      Les commentaires (après #) jouent le rôle des phrases de la démarche : chacun s’affiche quand sa ligne s’exécute. Double-clic sur le code pour le modifier.
